Advanced session credentials

      Connection details are saved on this stick. Header and environment credentials stay in memory; enter them again after restarting. OAuth-only providers require an access token. Environment references in imported project config are not expanded.

Skills

    
Reusable SKILL.md instructions for planning, reviews, and project workflows. Use /skill-name in your message, or let Lite discover enabled skills.

    
Finds packs in .claude/skills and .agents/skills in your project and home folder. Project and imported packs need review before use; changed instructions need a fresh review. Skill text does not grant permissions or automatically execute scripts.

    

    

    

    
Create or import a skill
      
      
      
      
      
      
      $ARGUMENTS is replaced with the text after the skill command. Skills are saved locally and kept by app updates. Shell preprocessing, forked agents and permission overrides from other apps are not executed.
