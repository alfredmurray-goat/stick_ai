# Stellan-1 Lite and Max model licensing and provenance

The MIT licence in LICENSE covers stick_ai software only. This repository does not contain or train Stellan weights. The provenance below records the model and training sources specified by localilabs; actual training records, revisions and permissions must be verified before releasing weights.

The runtime identifiers are `stellan-1-lite` and `stellan-1-max`. Each uses a separately supplied GGUF. This source update does not establish different base architectures, quantizations, training records or weight rights for those variants; verify each actual release against the declared provenance and TODOs below.

## Base and adaptation

- Base: [Mistral AI Devstral Small 2505](https://huggingface.co/mistralai/Devstral-Small-2505), under [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0). Attribution: Mistral AI.
- Adaptation: Stellan 1.0 LoRA fine-tune created by localilabs. Intended licence for localilabs adapter contributions: Apache 2.0, subject to completing the review below. No adapter licence grant or weight release is made by this source-only repository.
- A merged or quantized GGUF remains derived from the base. Retain the complete Apache 2.0 text and all applicable upstream notices, identify localilabs modifications and record adapter, merge and quantization revisions. A new name does not replace the base licence.
