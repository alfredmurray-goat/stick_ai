// how it worksSimple from the first step

It asks before it acts.

  1. 01
    Plug in, open. The app for your computer is right on the stick. Nothing to install.
  2. 02
    Ask in plain words. Stellan explores the project you choose, and only that project.
  3. 03
    Say yes or no. Every edit and command shows the exact lines first. Your file stays as it was until you allow it.

// built inA little help with the whole task

Small stick, grown-up tools.

thinking

Watch it think.

Stellan's reasoning and every file it reads stream into the chat as it works, then fold into one tidy line: Thought for 12 s · 2 steps.

You can see what it's thinking and which files it's looking at while it works, so it never feels like a black box.

memory

Rests when you do.

After 10 quiet minutes it gives your computer its memory back. Your next message reloads the model and continues the conversation.

hooks

Hooks, like Claude Code.It can tell you when it’s done.

Run your own command, or tell another app, when Stellan finishes or needs you. A hook can stop a step. It can never approve one.

It can let another app (or your phone) know when it has finished or needs your answer, so you don't have to sit and watch.

github

Works with your GitHub.

Connect the app to your GitHub account with a short code, no tokens to set up. Stellan works on the repositories you pick and opens a pull request for you to review.

If your code is kept on GitHub (where most developers store their projects), it can work on it there too, and hands its changes back for you to check before anything is final.

memory

More room when you need it.

Keep memory use modest by default. Turn on a longer conversation window in the sidebar for larger tasks, and keep private notes for each chat.

web

Web search, if you say so.

It can look up docs and error messages with Actuent. It asks first every time, and only the search words leave. Your code never does.

If it needs to look something up online, it asks you first, every time. Only the search words go out; your files never do. You can switch the internet off completely.

// benchmarks

80.5% on HumanEval pass@1. On your own computer.

These model scores were measured with the earlier llama.cpp harness. Full HumanEval results have not yet been measured on Stellan-Run.

In plain words: we tested the two AIs on the stick with 164 short Python programming puzzles. Lite solved 120 (73.2% pass@1); Max solved 132 (80.5% pass@1). These tests measure small coding tasks, not the ability to finish a whole project.

Full HumanEval runs, one attempt per problem: Stellan-1 Lite scored 120/164 (73.2% pass@1) on CPU; Stellan-1 Max scored 132/164 (80.5% pass@1) with GPU offload on Kaggle. Our results are pass@1. How we measured, and the small print

Stellan-1 Lite: all 164 HumanEval problems, pass@1, greedy decoding (temperature 0), each answer run against the official hidden tests, on a 4-core CPU with the app's own settings: 120 of 164 passed.

Stellan-1 Max, completed 22 November 2026: 132 of 164 passed (80.5% pass@1), with all 32 failures retained. The supplied result records GPU offload, a 4-core Xeon host and 31.3 GiB RAM. Median generation speed was 32.0 tokens/s in this run; this is not a CPU or USB speed measurement. Exact GPU devices and model/runtime hashes are absent from the receipt. This replaces the partial 26/30 CPU result. Raw results.

Historical sources: Anthropic’s Claude 2 model card, section 4.3, labels 71.2% as Codex P@1 (0-shot), using temperature 1. Google’s Gemini technical report gives 74.4% for Gemini 1.0 Ultra on HumanEval, 0-shot; we have not confirmed the pass@k setting, so that row is labeled as a reported score rather than pass@1.

Additional historical sources: the GPT-4 technical report reports GPT-4 at 67.0% and GPT-3.5 at 48.1%, 0-shot. Anthropic’s Claude 3 announcement reports Haiku at 75.9% and Sonnet at 73.0%, 0-shot. Mistral’s Codestral Mamba model card reports 75.0%. These entries retain the published scores and are not labeled pass@1 where the exact pass@k has not been confirmed. Older model names refer to those historical releases, not current products.

What pass@1 means: success with one generated answer, rather than finding any successful answer among 100 tries. Our run uses one greedy answer per task. Other evaluations can estimate pass@1 by averaging independent samples; this is not best-of-100. “0-shot” means no worked examples in the prompt, not a number of attempts.

Limits: matching pass@1 does not match prompts, sampling temperature, token budgets or test environments. These are historical reference scores, not a controlled head-to-head or a claim about today’s best models. This selection omits higher-scoring models, including GPT-4 Turbo and Llama 3 70B. It does not establish that Stellan leads HumanEval. Unspecified-metric scores are historical context, not evidence of a like-for-like advantage.

// no data centre

Your questions never visit a data centre.

Cloud AI like ChatGPT and Gemini answers from huge data centres that run around the clock, and many of them are cooled with water. stick_ai answers on the computer you already have, so your questions use none of that.

water

No cooling water.

Your questions never reach a data centre, so none of the water data centres use for cooling goes into your answers.

hardware

Nothing new to build.

It runs on the computer you already own. No servers are built, or kept running day and night, to answer you.

power

Only on when you are.

It uses your computer's power only while it's working, and rests by itself after 10 quiet minutes.

To be fair, the small print

Cloud AI has become very efficient per answer. Google reports about 0.24 Wh of electricity and 0.26 ml of water for a typical Gemini text prompt (August 2025), and OpenAI about 0.34 Wh for an average ChatGPT question (June 2025). A laptop working on an answer can use more electricity than that, so we don't claim stick_ai uses less energy per answer. What it avoids is the data centre itself: its cooling water, its servers and keeping them running around the clock.

// questions

Questions.

Do I need to know how to code?

No. You can ask in everyday words, like "add a contact form to my website" or "why is this page broken?". Stellan explains what it finds and shows proposed file changes for you to approve. It helps most if you have a website, app or code project, or you would like to start one.

When can I buy it?

It isn't on sale yet. Orders open in February 2027 with shipping across the European Union, and in May 2027 for the rest of the world.

How much is it?

€15 per stick in the EU, VAT included, and $17 in the rest of the world, plus shipping. It's a one-off price: no subscription.

How do I get started?

Plug in the stick, open the Stick AI app for your computer and choose Open workspace. Follow the first-time activation steps, choose a project folder and tell Stellan what you want to do. The app and models come on the stick; you don't need to install Node.js or Ollama. Read the first-open guide if your computer blocks the app.

What is the printed activation code for?

It links your purchase to your USB stick. First-time activation needs the code supplied with the stick and an internet connection. It sends the code and an identifier for the stick to the activation service, without needing your project files. The app saves a signed confirmation on the stick and checks it offline on later starts.

Does it need the internet?

Local coding and chat work offline after first-time activation. Optional app updates, GitHub workspaces, web search and remote tools use the internet. Allow internet is on by default; turn it off in Settings → Models for offline work. New-stick activation still needs one online connection. Review the information you approve sending when you use online tools.

Which computers does it work on?

Macs with Apple Silicon or Intel running macOS 13.5 or newer, Windows 10 and 11 on 64-bit Intel or AMD computers, and supported 64-bit Linux computers. Windows needs Edge WebView2; Linux needs glibc 2.35 or newer, GTK 3 and WebKitGTK 4.1. Lite is intended for computers with 8 GB of memory. Max can be selected from 16 GB, with 24 GB or more recommended.

What is the difference between Lite and Max?

Lite is the smaller model: it handles the conversation, plans the work and uses tools. Max is the larger coding model for bigger changes. On computers with 24 GB of memory or more, Lite can ask Max for coding help automatically. You can also use Lite on its own or choose Max directly when your computer has enough memory.

Why can Max be slow on a 16 GB computer?

Its model file is about 14.3 GB, which leaves little memory for the app and your operating system. The computer may repeatedly read data from the stick, making replies take many minutes or appear stuck. Lite is the default on 16 GB computers, and Max is never switched on automatically there. The app warns you before choosing Max directly.

Do I need a separate graphics card?

No. The app can run on the computer's processor. On supported Apple Silicon Macs it can also use the built-in graphics processor, with a processor-only fallback if that cannot start. Having enough memory still matters, especially for Max.

Why do some replies take a while?

The app checks the model files on the first start and loads the selected model. After that, reply times depend on your processor, available memory, stick speed and the size of the task. Follow-up steps can reuse work the model has already done. Watch the progress and thinking in the conversation; you can cancel the current step without closing the app.

Can I use the same stick on different computers?

Yes. The same stick includes apps for supported Macs, Windows PCs and Linux computers, sharing the model files on the stick. Close the app and safely eject the stick before moving it. Each computer still needs to meet the operating-system and memory requirements.

Can it change files without asking me?

It can read and search inside your project to understand the task. Saving or editing files, running commands and calling connected tools require your approval. File changes are shown as a before-and-after comparison. Review what you allow and keep backups or version history: AI can still make mistakes.

How should I read the benchmark scores?

Our reported Stellan-1 Lite result is 120 out of 164 HumanEval coding problems, or 73.2% pass@1. That measures short Python functions against tests, not whether it can build an entire app or solve every task. Scores from other models may use different prompts and settings, and Max scored 132 out of 164 (80.5% pass@1) in its completed run. Read the results and their limits, and check the code Stellan proposes.

What if my computer blocks the app on first open?

The current test builds are not signed with a trusted Apple or Microsoft certificate, so your computer may block them or ask for confirmation. Only open a copy from a source you trust. Follow the first-open guide for your computer; a security prompt alone is not proof that an app is safe.

Does it copy the AI onto my computer?

The full model files stay on the stick. While working, the app uses your computer's memory and temporary working files, and it can write app logs. Your operating system may also keep its own caches or swap data. You don't need to install Node.js or Ollama to use the prepared stick.

Does it work with GitHub?

Yes. In the app, open Settings → GitHub, click Sign in with GitHub and enter the short code it shows at github.com/login/device: no tokens or passwords to copy. There's no account on this website; the connection is between the app on your computer and GitHub. You choose exactly which repositories Stick AI may use. It downloads a copy to work on, and when you're happy it opens a draft pull request for you to review. It never changes your main branch, and the sign-in is kept only while the app is open, never saved to the stick.

Can it work with my other tools?

Yes. Like Claude Code, it supports MCP servers (tools from other apps), skills (reusable instructions) and hooks (your own commands or apps that run when Stellan sends a message, uses a tool, needs your approval or finishes). Hooks can stop a step but can never approve one: changes always wait for you. Online services have their own permissions and may have their own limits or fees.

How do app updates work?

With internet access enabled, the app can check for signed updates. When one is available, you can install it from the app. Updates are checked before installation and keep your models and projects in place, so you don't have to download the large model files again. You can keep using the current version offline.

How do I stop it and remove the stick?

Use Cancel to stop the current step. This does not undo changes you already approved. When you have finished, close the app, let it shut down and use your computer's safe-eject option before unplugging the stick. Avoid removing it while it is working or saving files.

Do I pay for shipping?

Yes. Shipping is added at checkout and depends on where the stick is going.
