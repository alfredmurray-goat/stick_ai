Your private coding assistant, on a stick.

Stellan, the AI, runs entirely on your own computer. Your code and your questions never leave it.

Start in five steps

  1. Plug the stick into a Mac, Windows PC or Linux computer.
  2. Open the app for your computer straight from the stick:
    Stick AI Mac · Stick AI.exe Windows · stick-ai Linux.
    If your computer warns you the first time, see the back of this guide.
  3. Enter your activation code (below). The first start needs the internet for a few seconds to activate this stick; after that, it works offline.
  4. Click Open workspace. The first start takes a few minutes while the models are checked; then it starts in seconds.
  5. Follow the short welcome tour, then ask Stellan anything about your code.

Every day

Ask in plain words

“Why does checkout crash?” or “Add a dark mode toggle.” You see Stellan think and which files it reads, live.

You say yes or no

Every change shows the exact lines first. Click Allow changes or Keep my file. Commands and web searches ask too.

It checks its own work

Stellan can run your project's tests, after you allow it, and fix what fails.

Works with GitHub

Settings → GitHub: sign in with a short code, choose your repositories, and get a pull request to review.

Big projects

Settings → Models → Long context mode keeps far more in view. It can be slower.

Saves your computer

After 10 quiet minutes Stellan rests to free memory. Your next message wakes it.

If your computer warns you the first time

stick_ai isn't signed with a paid Apple or Microsoft certificate, so your computer may ask once. That's expected.

MacClick Done, open System Settings → Privacy & Security, click Open Anyway next to Stick AI, then open it again and confirm.

WindowsClick More info, then Run anyway.

LinuxRight-click stick-ai → Properties → Permissions → Allow executing file as program.

Good to know

  • Private by design. The internet is only used for activation, app updates, GitHub and web searches you allow. Your code is never sent anywhere.
  • Lost your code, or a new stick? Contact us through the website and we'll help you activate again.
